# DuckPit — Акт I «Яма просыпается» (веб-версия, черновик)

**Играть:** https://mrak0be5.github.io/duckpit-act1/

Аркадный idle про цех и Яму: собирай уток, мячи и ящики, неси их к Яме, выполняй норму отдела, прокачивай цех и спускайся на лифте всё глубже. Вся графика, модели и звуки сгенерированы кодом с нуля.

**Управление:** WASD / стрелки — ходьба (или зажмите мышь/палец и ведите — экранный джойстик), кнопки — мышью/тапом.

**Состояние сборки:** черновик в разработке.
- Отделы 1–2 («Мастерская», «Логистика») — играбельны полностью.
- Отделы 3–4 («Спортзал», «Накопитель») — частично: идёт сборка модулей (прокачки «Ступени цеха», Свисток, Турбо, дрон, склад с педалью, Эволюция Ямы).
- В веб-версии пока нет музыки (только звуковые эффекты); реклама и покупки — заглушки.

Unity 6 (WebGL). Лучше всего открывать в Chrome/Edge на компьютере.
